# Background reading

This folder retains the project's research references. Papers are background
material; the implemented protocol is documented in
[METHODOLOGY.md](../docs/METHODOLOGY.md).

For a first reading session:

1. Start with `5._CR._30._Recent_Advances_in_Reinforcement_Learning_for_Traffic_Signal_Control_A_Survey_of_Models_and_Evaluation-2.pdf` for the survey reference.
2. Read `Reinforcement_Learning_for_Traffic_Signal_Control_in_Hybrid_Action_Space.pdf` alongside the state/action code.
3. Use the multi-agent and partial-detection references when discussing extensions beyond the current single-intersection setup.

Keep original paper filenames so they remain identifiable. When introducing a
new research claim or adopting a method, cite its source in the relevant guide
or experiment notes and distinguish it from the current implementation.
