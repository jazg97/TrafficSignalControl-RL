# Project guides

Read these in order for a first lab session:

1. [Getting started](GETTING_STARTED.md): environment setup, first checks and a small PPO run.
2. [Methodology](METHODOLOGY.md): state, actions, reward, architecture and evaluation scope.
3. [PPO experiments](OPTIMIZED_PPO.md): full training/evaluation, checkpoints and recorded replays.
4. [Controlled baselines](BASELINES.md): max-pressure, a-priori PPO and historical timing/RNG caveats.

The [code map](../Code/README.md) explains module responsibilities. The
[notebook guide](../notebooks/README.md) identifies which notebooks require
historical data. [Repository cleanup notes](REPOSITORY_CLEANUP.md) record the
handoff reorganization and where local backups were preserved.
